# Documentos Oficiais - Vetline

Para disponibilizar o PDF oficial dos **Termos de Uso e Condições Gerais**:

1. Salve o arquivo PDF nesta pasta (`public/docs/`) com o nome:
   `termo_de_uso.pdf`

2. O sistema já está 100% configurado para:
   - Apontar o link e o botão **"Abrir Termo em PDF"** diretamente para `/docs/termo_de_uso.pdf`.
   - Permitir visualização e download imediato pelo navegador de forma segura.
